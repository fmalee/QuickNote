# QuickNote

面向 macOS 开发者的本地优先（Local-First）Markdown 闪念捕捉、知识工作台与项目协作工具。所有笔记以纯文本 `.md` 存储在你指定的本机目录中，零锁定、零遥测。

---

## 1. 三种工作形态（什么时候用哪种）

| 形态                        | 触发方式                                                        | 适用场景与特点                                                                                                                                                                                                  |
| --------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Quick Bar 全局浮层**      | 全局热键 `⌃⌥Space`（备用 `⌃⌥⌘Space`）                           | 任何全屏 App（IDE / 浏览器 / 终端）上方直接呼出，**不切 Space、不抢菜单栏、默认失焦即关闭（点图钉或「窗口 > 固定 Quick Bar」固定后失焦不关闭）、切 Space 自动收起并留存草稿**；支持「记录 / 打开 / 命令」三模式 |
| **主工作台（标准 / 全屏）** | 菜单栏图标、`⇧⌘↵` 或双开唤醒                                    | 深度写作、整理笔记与查阅项目文档；按 `⌃⌘F` 进入独立全屏 Space（可在 Mission Control `⌃↑` 拖至主工作应用左侧，macOS 自动记忆排序）                                                                               |
| **45% 侧栏辅助窗口**        | 「视图 > 切换 45% 侧栏辅助模式」或 Quick Bar 的「45% 侧栏」按钮 | 一边全屏看文档/报错、一边同屏右侧对照记录；贴靠当前屏幕右侧 45%（可在设置中调 `30%–60%`），侧栏内右上角「退出侧栏辅助」，左侧栏走覆盖式抽屉，**不触发 Split View、不改变背景 App 窗口尺寸**                     |

> 主窗口与设置窗口都隐藏时，应用自动切为 macOS `.accessory`（隐藏 Dock 图标、仅托盘常驻）；打开任一窗口时自动恢复 `.regular`（显示 Dock 与完整顶栏菜单）。

## 2. 高频快捷键速查

### 全局与 Quick Bar

| 快捷键             | 功能                                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| `⌃⌥Space`          | 呼出 / 隐藏 Quick Bar（若与输入法冲突可在「设置 > 通用与热键」一键切至备用 `⌃⌥⌘Space`）                                          |
| `⌘N`               | 切换至 Quick Bar 记录模式                                                                                                        |
| `⌘1` / `⌘2` / `⌘3` | Quick Bar 记录模式切换：列表 `- ` / 待办 `- [ ] ` / 纯文本段落                                                                   |
| `⌘T`               | 手动切换本次捕捉的目标笔记                                                                                                       |
| `⌘↵`               | 追加到目标笔记并弹出 5 秒非激活撤销 Toast（点撤销不抢原 App 焦点）                                                               |
| `⇧⌘↵`              | 追加并在主窗口打开目标笔记                                                                                                       |
| `⌥⌘↵`              | 将捕捉内容另存为新笔记（可选模板）                                                                                               |
| `⌘K`               | 切换至快速打开模式（`/` 路径补全、`#` 标签、`@` 工作区、`>` 动作，纯 Rust 受控探测与目录直扫；Quick Bar「打开 ⌘K」具备同样能力） |
| `⌘⇧K`              | 切换至命令库模式（`↵` 复制、`⌘↵` 在外部终端打开目录不粘贴、`⌘O` 跳源文件）                                                       |
| `Esc`              | 非记录模式下直接隐藏；记录模式下关闭浮层并保留未提交草稿                                                                         |

> Quick Bar 默认失焦即关闭；点图钉或「窗口 > 固定 Quick Bar」固定后失焦不关闭。

### 主窗口与 Markdown 编辑

| 快捷键                      | 功能                                                                                                                       |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `⌘N` / `⌘S` / `⌘W` / `⇧⌘T`  | 新建笔记（模板）/ 立即保存 / 关闭标签 / 恢复刚关闭的标签                                                                   |
| `⌃⇥` / `⇧⌃⇥`                | 切换至下一个 / 上一个标签（标签可拖动排序，右键菜单可删除文件到废纸篓；关闭按钮默认隐藏，可在「设置 > 外观与编辑器」打开） |
| `⌘F` / `⌥⌘F`                | 在编辑器中查找 / 查找并替换                                                                                                |
| `⌘K` / `⌘⇧K` / `⌘,`         | 快速打开 / 命令库 / 打开设置窗口（仅从菜单栏或 `⌘,` 进入）                                                                 |
| `⌘B` / `⌘I` / `⌥⌘C` / `⌥⌘G` | 加粗 / 斜体 / 代码块 / 插入表格                                                                                            |
| `⌥⌘X` / `⌥⌘K` / `⌥⌘I`       | 切换待办复选框 / 插入链接 / 插入图片（也支持直接粘贴截图或拖入本地图片至 `assets/YYYY-MM/`）                               |
| `⌥⌘L` / `⌥⌘Q` / `⌥⌘1`…`⌥⌘6` | 无序列表 / 引用块 / 1–6 级标题                                                                                             |
| `Tab` / `⇧Tab`              | 上下文缩进（列表按父级 marker 对齐、引用增减 `> `、代码块按代码缩进、普通段落软空格防误触代码块）                          |
| `⌘ + 单击链接`              | 打开外链、站内相对链接或中文标题锚点（可在设置改为单击打开；本地绝对路径弹确认框）                                         |

### 左侧栏视图与底部终端

左侧栏顶层导航顺序：`目录｜标签｜最近｜相关｜大纲`。

| 快捷键        | 功能                                                                                                 |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| `⌃⌘O` / `⌃⌘R` | 切换左侧栏视图：大纲 / 相关（前 20）                                                                 |
| `⌃⌘T`         | 开关编辑器下方内嵌终端（支持拖动调整高度）                                                           |
| `⇧⌘O` / `⌥⌘T` | 在访达中显示当前文件 / 在外部终端中打开项目目录                                                      |
| 终端聚焦隔离  | `⌥⌘C` 自动吞掉防误插代码块；`⌘C` 有选区复制/无选区放行；`⌘V` 原生直贴命令行；`⌃C`/`⌃D`/`⌃Z` 直传终端 |

> 绝大多数应用内快捷键均可在「设置 > 快捷键」自定义录制与冲突检测。

## 3. 核心特色用法

- **智能捕捉路由**：Quick Bar 会自动识别当前工作区与最近活跃文档（优先追加至文档内 `## 想法` / `## 待办` 分区），无活跃上下文时安全落入 `inbox.md` 的当日日期分区；追加 5 秒内可从右上角非激活 Toast 一键撤销。
- **收件箱清理**：`inbox.md` 默认置顶显示在「目录」里，超过 500 行时顶部轻提醒；选中若干行后点击文档头「移到新笔记…」即可一键抽离成独立笔记并从收件箱移除。
- **废纸篓安全删除**：应用内删除笔记、目录或标签右键删除操作均移到系统废纸篓，可从废纸篓还原。
- **命令书写法**：将笔记类型设为 `command-book`（或放入 `commands/`），以 `## 分组` + `### 命令标题` + 围栏代码块编写，可在块前附加元注释：
  ````markdown
  ### 强制清理未跟踪文件

  <!-- keywords: git clean reset -->
  <!-- danger -->

  ```bash
  git clean -fd
  ```
  ````
  `<!-- danger -->` 会在命令面板醒目标红警示；`⌘⇧K` 检索命中后 `↵` 复制、`⌘↵` 仅打开对应工作区终端目录绝不自动执行。
- **内嵌终端折叠保活与自动回收**：每工作区至多 1 个会话、全局上限 3 个；切去大纲或折叠面板**不会杀掉正在跑的服务**（选项卡旁显示绿色运行点 `●`），后端 1MB 环形缓冲蓄水、切回毫秒级恢复；隐藏且无前台子进程连续闲置 30 分钟（可在「设置 > 外部与搜索」调整或设为 `0` 关闭）自动回收防遗忘泄漏；超 10MB 刷屏自动暂停防卡死。
- **外部修改冲突与并排合并**：编辑器干净态时自动静默同步磁盘修改；若存在未保存草稿且磁盘被外部改动，自动暂停保存并弹出四选一冲突横幅，点击**「并排对比」**进入 CM6 `MergeView`（左只读磁盘最新、右可编辑本地，支持逐块采纳与乐观并发写回）。
- **富文本复制与导出 PDF**：文档头 `[⋯]` 菜单或顶栏菜单支持「复制为富文本」（HTML + 纯文本双 MIME，直接粘贴至飞书/邮件/备忘录）与「导出为 PDF…」（离屏打印级 A4 排版）。
- **工作区与外部动作**：在左侧目录树右键「绑定工作区配置」编辑该目录的 `.quicknote.yaml`（配置 `vscodeWorkspacePath`、`projectRoot`、`defaultTerminalCwd` 等）；在「设置 > 外部与搜索」配置外部终端（默认 iTerm2，可切换系统 Terminal / Warp / Ghostty）、VS Code / Sublime。

## 4. 本地数据位置与排障指南

- **笔记库目录**：默认 `~/Documents/QuickNote`（首次引导或「设置 > 库与收件箱」可随时更改）。
  - `inbox.md`：默认收件箱
  - `_templates/`：Markdown 新建模板
  - `assets/YYYY-MM/`：粘贴/拖入的图片附件
- **应用状态与配置目录**（macOS）：`~/Library/Application Support/com.joey.quicknote/`
  - `settings.yaml`：唯一配置文件（支持手改热重载；语法错误时保持原文件**只读不覆写**，顶部报错精准定位行列号/未知字段，并提供一键打开修复）
  - `ui-state.json`：窗口形态、标签页、面板宽度、筛选状态、左侧栏宽度与视图、底部终端高度
  - 缓存目录下按笔记库哈希隔离的 `vaults/<vault_hash>.db`（含 `-wal` / `-shm`）：可随时删库重建的派生全文索引（顶栏「工具 > 重建索引」），严禁放入笔记库根目录
  - `backups/`：覆盖冲突与导入设置前的自动滚动备份（支持在「设置 > 通用与热键」手动导出/导入配置备份）
  - `recovery/`：每 2 秒自动落盘的脏标签崩溃恢复快照
  - `bookmarks.json`：外部文件 / 目录书签

## 5. 本地开发、验收与 macOS 打包

### 环境要求

- macOS 12+（推荐 Apple Silicon / macOS 13+，依赖 Xcode Command Line Tools）
- Node.js 22+、`pnpm`（`packageManager: pnpm@12.21.0`）
- Rust 工具链（`rustc` / `cargo`）

### 常用命令

```bash
# 安装依赖
pnpm install

# 启动本地桌面开发模式
pnpm tauri dev

# 运行全套 9 项工程门禁（绑定零差异 / 架构检查 / 格式 / Lint / 类型 / 前后端全量测试）
pnpm check:all

# 运行万篇文档 Release 性能压测
cargo test --manifest-path src-tauri/Cargo.toml --release --test m4_performance_budget -- --nocapture

# 仅构建前端生产产物
pnpm build

# 打包 macOS 桌面应用（产出 .app 与 .dmg）
pnpm tauri build

# 仅打包 macOS .app（不生成 .dmg）
pnpm build:app
```

### 打包产物说明

- `pnpm tauri build` 产出：`src-tauri/target/release/bundle/macos/QuickNote.app`（约 18.7 MiB）与 `src-tauri/target/release/bundle/dmg/QuickNote_2.0.0_x64.dmg`（约 6.3 MiB）。
- `pnpm build:app` 产出：仅 `src-tauri/target/release/bundle/macos/QuickNote.app`。
- `.app` 内部结构干净：`Contents/MacOS`（19M，内嵌前端静态资源与 bundled SQLite）、`Contents/Resources`（52K，仅 `icon.icns`，无多余 `.lproj` 语言包）、`Contents/Info.plist`（4.0K）。`src-tauri/icons/` 仅保留源图 `app-icon.svg` 与 macOS 打包所需的 4 个图标文件，其余平台图标已清理。

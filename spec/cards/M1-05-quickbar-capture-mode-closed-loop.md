- 所属里程碑：M1
- 关联方案与契约：`v4` §1.2–§1.5、§3.5.1、§3.9（A/B/C）、§5.4、§6 M1；`C1.2`、`C2.2`、`C4.2`、`C4.3`、`C6.1`、`C6.3`、`C7.1`、`C7.2`、`C8.1`–`C8.3`、`C9.1`、`C9.3`、`D-0001`–`D-0003`、`D-0006`
- 前置依赖：`M1-04`
- 会话策略：独立新会话执行；完成后提交并结束会话

## 1. 目标范围（做什么 / 明确不做什么）
- 要做：
  - 在 `src/features/quickbar/` 升级 `QuickBarView.vue`、`store.ts` 与子组件，完整交付 **Quick Bar 记录模式（Capture Mode）** 端到端闭环：
    - **实时目标解析与顶部 Chip（`C8.1`）**：每次呼出 Quick Bar（收到 `window:state` `visible == true`）或切换工作区时，读取主窗口可见态、当前激活文档与 `ui-state.json` 的 `selectedWorkspaceKey`，调用 `capture_resolve_target` 展示 `文档名 › 分区 · 工作区`（跨工作区回退时高亮显示 `收件箱 · 跨工作区`；普通文档缺失目标分区且未开启自动创建时提示“将追加到文末”）。
    - **内容模式切换与按工作区记忆（`v4` §1.3、`C6.3`）**：支持 `⌘1`（列表）、`⌘2`（待办）、`⌘3`（正文）一键切换；目标为 `inbox.md` 时默认列表模式，其余目标按当前工作区记忆到 `ui-state.json` 的 `workspaceModes`。
    - **`⌘T` 目标选择器弹层**：支持在浮层内按 `⌘T`（或点击顶部目标 chip）打开轻量选择器，支持检索选择最近文档、按标签筛选、一键指定 `inbox.md`，以及**切换或清除“锁定工作区（`selectedWorkspaceKey`）”**（持久化至 `ui_state_set`）。
    - **相关笔记快速改投（`v4` §1.2、§3.5.1、`C2.2`）**：当输入框内容 `>= 2` 个字符时，以 `80ms` 防抖 + 递增 `requestId` 调用 `search_notes_and_files(limit = 3)`，在底部实时展示最多 3 条相关笔记；支持 `⌘↑` / `⌘↓` 选中改投目标（显式选中后不受工作区过滤限制），再次按键或清空可恢复默认目标。
    - **草稿持久化与恢复（`v4` §1.5、`C6.1`）**：输入过程防抖保存草稿（含文本、当前模式、显式目标）；通过 `Esc`、`⌃⌥Space` 或切 Space（`HideReason = "space_changed"`）隐藏浮层时完整保留草稿，下次呼出无缝恢复；仅当提交成功（`⌘↵` / `⇧⌘↵`）或用户显式清空时删除草稿。
    - **双提交动作与跨窗口协同（`v4` §1.4–§1.5）**：
      - `⌘↵`（追加并关闭）：调用 `note_append` 写入目标文档 → 清空草稿 → 调用 `window_hide_quick_bar` 关闭浮层 → 后端触发 5 秒非激活 Toast 浮窗（或前台主窗口 Toast）展示 `已追加至「<文档名>」 · [撤销]`；若目标文档已在主窗口打开，主窗口通过监听事件无感刷新最新内容与大纲。
      - `⇧⌘↵`（追加并升级打开主窗口）：调用 `note_append` 写入目标文档 → 清空草稿并隐藏 Quick Bar → 调用 `window_show_main`（触发 `.accessory → .regular` 动态切换）→ 主窗口自动打开/激活该目标文档标签页、将编辑器光标定位至刚追加内容的末尾并确保右侧大纲面板展开。
- 不做：
  - 不实现 `⌥⌘↵` 另存为独立新笔记的目录/模板选择弹窗（归 `M2` 模板系统卡片）。
  - 不实现 Quick Bar 打开模式（`⌘K` 路径补全/Spotlight）与命令模式（`⌘⇧K` 命令书检索/开外部终端）（归 `M3`；本卡在切换至打开/命令标签时保持轻量占位提示，且按 `Esc` 可先退回记录模式）。

## 3. 具体实现要求
- **防竞态与焦点纪律（`C2.2`、`D-0001`、`D-0002`）**：
  - 相关笔记检索与 `⌘T` 选择器过滤必须遵守 `80ms` 防抖与递增 `requestId` 校验，过期响应严禁覆盖当前列表。
  - 在 `⌘T` 目标选择器打开状态下按 `Esc`，仅关闭选择器并将焦点交还 Quick Bar 输入框，不得直接关闭整个 Quick Bar 面板；当处于打开/命令模式占位态按 `Esc` 时先退回记录模式，在记录模式且无子弹层时按 `Esc` 才隐藏面板并保留草稿。
- **跨工作区防误追可视化（`C8.1`）**：当 `ResolvedTarget.isCrossWorkspaceFallback == true` 时，顶部目标 Chip 必须以醒目样式展示 `收件箱 · 跨工作区`，提醒用户当前锁定工作区与上次活跃文档分属不同项目。
- **零裸色值与分层合规（`C1.2`、`C7.1`）**：新增的目标选择器、相关笔记条与底部快捷键提示栏全部使用 `--qn-*` CSS Token，不直连 `@tauri-apps/api`。
